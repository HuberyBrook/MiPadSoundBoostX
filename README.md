## EN

This is a Magisk/KernelSU sound quality enhancement module for the Xiaomi or REDMI Mi Pad

## How to Use 🚀

1. Download the appropriate release version, ensuring the file extension is .zip.
2. Open Magisk / KernelSU or any compatible branch, then select and install the module from the modules directory.
3. Follow the on-screen prompts and press the Volume Up/Down keys to complete pre-installation steps.
4. Reboot your system to experience the module.

## Related Issues ⚠️

1. If the Settings → Sound & touch → Sound Effects crashes or becomes unavailable after installing the module:
      This is caused by replacing the Misound APK during module installation.

#Solutions 🔧

1. Reinstall the Misound APK

· Ensure that Core Patch or similar modification modules are enabled and reboot if necessary.
· Navigate to /product/app/misound/ using a file manager and install misound.apk.

2. Reinstall This Module (Refer to "How to Use" above)

· When prompted whether to replace the Misound APK, choose "Do not replace".

✅ Follow these steps carefully to ensure proper installation and functionality.

## CN

这是一个专为高通骁龙芯片的小米/红米平板的音质优化模块，可适用于Magisk 和 KernelSU

## 如何使用 🚀

1.下载适合的发行版，保证拓展名为.zip格式。
2.打开Magisk/kernelSU或者其拓展分支，在在模块目录选择文件模块安装。
3.根据提示点击左右音量键，完成前置安装。
4.重启系统，即可体验本模块。

## 相关问题 ⚠️

1.若安装模块后出现 设置 → 声音与触感 → 音质音效。闪退不可用的情况，出现问题的原因:
在安装模块时选择了替换音质音效apk文件。

## 解决方法 🔧

1.安装模块音质音效

· 保证核心破解相关模块启用并重启
· 前往系统文件管理安装 /product/app/misound 位置的 misound.apk 文件

2.重新安装本模块(详细见＂如何使用＂)

· 在现在是否替换音质音效相关选择时，选择不替换音质音效。
